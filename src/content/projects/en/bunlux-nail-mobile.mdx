overview: >-
  Engineered a customer-facing mobile application using React Native and Expo to modernize nail salon booking processes. The platform solves the inefficiencies of manual phone reservations by allowing users to browse interactive nail art catalogs, check technician availability in real-time, and seamlessly book appointments. Built with NativeWind to ensure a highly responsive and consistent user interface across both iOS and Android platforms.
features:
  - "Cross-Platform Architecture: Developed a unified codebase for iOS and Android using Expo, significantly reducing development time."
  - "Real-Time Booking Engine: Implemented a robust booking system with live technician availability checks."
  - "Interactive Style Gallery: Created a dynamic nail art catalog for users to browse and select styles before booking."
  - "Automated Push Notifications: Integrated a notification system for automated appointment reminders and status updates."
  - "Secure Authentication: Implemented secure user authentication and comprehensive booking history tracking using Supabase."
challenges:
  - problem: "Achieving a highly consistent and responsive UI styling across both iOS and Android platforms."
    solution: "Integrated `NativeWind` to leverage Tailwind CSS utility classes within React Native, ensuring a perfectly unified design system while maintaining native rendering performance."
  - problem: "Handling complex and deeply nested navigation flows, such as Tabs inside Stack Navigators."
    solution: "Implemented `Expo Router` (file-based routing) to elegantly manage complex nested navigation states, drastically reducing boilerplate code and improving routing logic."
