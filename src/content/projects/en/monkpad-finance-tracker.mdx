overview: >-
  Architected MonkPad, a personal finance web application designed to revolutionize individual expense tracking. To eliminate the friction of manual data entry, the platform integrates Optical Character Recognition (OCR) technology to automatically scan banking transaction slips and intelligently categorize expenses. Coupled with an interactive dashboard, it provides users with clear visual insights into their spending habits and automated financial reports, resulting in a highly efficient financial management tool.
features:
  - "Smart OCR Integration: Implemented optical character recognition to scan transaction slips and extract expense data automatically."
  - "Interactive Analytics Dashboard: Built a dynamic dashboard using Recharts to visualize spending trends and overall financial health."
  - "Automated Categorization: Developed logic to automatically categorize expenses based on the extracted merchant data from slips."
  - "Comprehensive Reporting: Generated automated monthly and yearly financial reports for easy tracking and budgeting."
  - "Secure Authentication: Integrated a robust user authentication and profile management system to protect sensitive financial data."
challenges:
  - problem: "Accurately parsing and structuring text extracted from highly diverse and unstructured banking slip formats."
    solution: "Engineered a custom parsing and regex-based logic post-OCR extraction to accurately identify and map key information, such as dates, amounts, and merchant names, significantly reducing manual corrections."
  - problem: "Visualizing complex financial data in a way that is immediately understandable and actionable for general users."
    solution: "Integrated Recharts to render highly interactive bar and pie charts, enabling users to seamlessly drill down into specific spending categories with a clean UI."
