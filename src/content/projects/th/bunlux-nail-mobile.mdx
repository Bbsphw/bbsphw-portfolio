overview: >-
  โปรเจกต์นี้เป็นการพัฒนาแอปพลิเคชันมือถือสำหรับลูกค้า (Customer-facing) ด้วย React Native และ Expo เพื่อยกระดับกระบวนการจองคิวร้านทำเล็บ ตัวแอปพลิเคชันเข้ามาช่วยแก้ปัญหาความยุ่งยากจากการจองคิวผ่านโทรศัพท์แบบเดิม โดยผู้ใช้สามารถเลือกดูลายเล็บผ่านแค็ตตาล็อกอินเทอร์แอคทีฟ เช็กคิวว่างของช่างทำเล็บได้แบบเรียลไทม์ และทำการจองคิวได้อย่างสะดวกรวดเร็ว นอกจากนี้ยังมีการประยุกต์ใช้ NativeWind ในการจัดโครงสร้าง UI เพื่อให้แอปพลิเคชันแสดงผลได้อย่างสวยงาม ตอบสนองไว และเป็นมาตรฐานเดียวกันทั้งบน iOS และ Android
features:
  - "Cross-Platform Architecture: พัฒนาแอปพลิเคชันด้วยโค้ดเบสเดียว (Unified codebase) สำหรับทั้ง iOS และ Android ผ่าน Expo ช่วยลดระยะเวลาในการพัฒนา"
  - "Real-Time Booking Engine: ระบบจองคิวทำเล็บที่มีการดึงสถานะคิวว่างของช่างแบบเรียลไทม์ ป้องกันการจองคิวซ้อนทับกัน"
  - "Interactive Style Gallery: แค็ตตาล็อกลายเล็บออนไลน์ที่ช่วยให้ลูกค้าสามารถเลือกดูและตัดสินใจเลือกลายก่อนทำการจอง"
  - "Automated Push Notifications: ระบบแจ้งเตือนอัตโนมัติเพื่อเตือนความจำเมื่อใกล้ถึงเวลานัดหมาย และอัปเดตสถานะการจอง"
  - "Secure Authentication: ระบบยืนยันตัวตนที่ปลอดภัยและระบบเก็บประวัติการจองคิวย้อนหลังอย่างละเอียดโดยใช้ Supabase"
challenges:
  - problem: "ความท้าทายในการทำให้ UI แสดงผลได้อย่างสม่ำเสมอและตอบสนองได้ดีทั้งบนแพลตฟอร์ม iOS และ Android"
    solution: "นำ `NativeWind` มาประยุกต์ใช้เพื่อเขียน Utility Classes ของ Tailwind CSS ภายในคอมโพเนนต์ของ React Native ช่วยให้การออกแบบ UI เป็นไปในทิศทางเดียวกันทั้งหมด โดยที่ยังคงประสิทธิภาพระดับ Native"
  - problem: "การจัดการการนำทาง (Navigation) ที่ซับซ้อน เช่น การซ้อน Tabs ไว้ภายใน Stack Navigators"
    solution: "ใช้งาน `Expo Router` ซึ่งเป็นระบบ File-based routing เข้ามาช่วยจัดการสเตตัสการนำทางที่ซับซ้อน ช่วยลดความยุ่งยากของโค้ด (Boilerplate) และทำให้ตรรกะการเปลี่ยนหน้าเข้าใจได้ง่ายขึ้น"
