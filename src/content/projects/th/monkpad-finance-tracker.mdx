overview: >-
  ออกแบบและพัฒนา MonkPad เว็บแอปพลิเคชันสำหรับจัดการการเงินส่วนบุคคลที่มุ่งเน้นการปฏิวัติรูปแบบการจดบันทึกรายรับรายจ่าย เพื่อขจัดความยุ่งยากในการพิมพ์ข้อมูลด้วยตนเอง (Manual Data Entry) แพลตฟอร์มนี้จึงได้บูรณาการเทคโนโลยี Optical Character Recognition (OCR) เข้ามาช่วยสแกนสลิปโอนเงินธนาคารและจัดหมวดหมู่รายจ่ายให้โดยอัตโนมัติ นอกจากนี้ยังมี Interactive Dashboard ที่ช่วยสรุปพฤติกรรมการใช้จ่ายและสร้างรายงานทางการเงิน เพื่อให้ผู้ใช้สามารถวางแผนการเงินได้อย่างมีประสิทธิภาพ
features:
  - "Smart OCR Integration: นำเทคโนโลยี OCR มาประยุกต์ใช้เพื่อสแกนสลิปโอนเงิน และดึงข้อมูลรายจ่ายแบบอัตโนมัติ"
  - "Interactive Analytics Dashboard: สร้างหน้าแดชบอร์ดแบบไดนามิกโดยใช้ Recharts เพื่อแสดงภาพรวมแนวโน้มการใช้จ่ายและสถานะทางการเงิน"
  - "Automated Categorization: พัฒนาระบบตรรกะเพื่อจัดหมวดหมู่ค่าใช้จ่ายโดยอัตโนมัติ โดยอ้างอิงจากข้อมูลชื่อร้านค้าที่ดึงมาได้จากสลิป"
  - "Comprehensive Reporting: ระบบสร้างรายงานสรุปผลทางการเงินแบบรายเดือนและรายปี เพื่อช่วยในการติดตามและการตั้งงบประมาณ"
  - "Secure Authentication: ติดตั้งระบบยืนยันตัวตนและการจัดการโปรไฟล์ผู้ใช้ที่มีความปลอดภัยสูง เพื่อปกป้องข้อมูลทางการเงินส่วนบุคคล"
challenges:
  - problem: "การแปลงข้อความและดึงโครงสร้างข้อมูลจากรูปแบบสลิปธนาคารที่มีความหลากหลายและไม่มีโครงสร้างที่ตายตัว"
    solution: "เขียนตรรกะแบบ Custom Parsing และ Regular Expression (Regex) เพื่อดึงและจัดผังข้อมูลหลังจากการทำ OCR ให้สามารถคัดแยกวันที่ จำนวนเงิน และชื่อร้านค้าได้อย่างแม่นยำ ช่วยลดภาระผู้ใช้ในการแก้ไขข้อมูล"
  - problem: "การนำเสนอข้อมูลทางการเงินที่มีความซับซ้อนให้ออกมาเข้าใจง่ายและเกิดประโยชน์สูงสุดต่อผู้ใช้งานทั่วไป"
    solution: "นำไลบรารี Recharts มาช่วยสร้างกราฟแท่งและกราฟโดนัท (Pie charts) แบบอินเทอร์แอกทีฟ ช่วยให้ผู้ใช้งานสามารถเจาะลึกดูหมวดหมู่การใช้จ่ายในแต่ละส่วนได้อย่างราบรื่นผ่าน UI ที่สะอาดตา"
